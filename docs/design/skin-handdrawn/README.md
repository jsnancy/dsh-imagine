## 换了什么

**不只是换色，版面语言一起换了：**

- **纸**：暖白纸底 + 纸张噪点 + 边缘暗角；弹层像一张单独撕下来的纸，顶部贴一条半透明黄胶带。
- **笔**：标题、分节号、按钮用翩翩体（HanziPen SC）；正文用手札体（Hannotate SC）；编号/计数用 Bradley Hand；注释小字退回系统字体保证清晰。
- **线**：边框一律不规则圆角（手抖感）+ 硬阴影；分隔线用虚线；标题下划线和选中的 tab 下沿是朱红手绘波浪线。
- **贴**：模板卡是贴纸墙——交替 0.4～0.9 度微旋转、顶部一条小胶带、悬停抬起并回正；左侧栏的选中项是一道马克笔黄高亮。
- **记**：额度四格变成米黄/淡粉/淡蓝/淡绿四张便签，各配一条朱红短横线；提示词输入框是一页方格纸，文字压在格线上。
- **涂**：分节号 01 外面手绘圈一圈；标题旁一颗手绘小星；搜索框、下拉、按钮都换成手绘边与手绘小三角。

## 如果落地，成本是多少

- **纯 CSS 皮肤**：`lib/skin-handdrawn.css`，由 Host 在 `/image-studio/skin.css` 提供、面板注入，约 1300 行，**不改任何 DOM 结构、不改任何业务逻辑**。
- 需要配套的只有：顶部加一个「手绘 / 原版」的皮肤开关（或跟随设置），以及 `icon.png` 是否换成手绘版图标。
- 深色主题目前被整页覆盖成浅色纸（纸天然是浅色）。若你要，我可以再出一版「牛皮纸 / 黑板」深色变体，两版共存。

## 需要你定夺的四件事

1. **要不要落地？** 落地后我会把它做成可切换皮肤，默认跟随你的选择。
2. **卡片微旋转的幅度**：现在 0.4～0.9 度，很克制；要不要再明显一点（更像手账）？
3. **字体清晰度取向**：正文手札体（手写感强、12px 以下略糊）vs 系统字（清晰但手绘感弱）。截图里注释小字已经改用系统字。
4. **深色要不要也手绘化**（牛皮纸/黑板变体），还是深色保持现在的原版？

## 怎么自己看

皮肤已在本地预览服务里生效：

```bash
node /tmp/harness/serve.mjs   # http://127.0.0.1:8791
```

去掉 `<link rel="stylesheet" href="/skin.css">` 即回到原版，便于来回对比。
