# 精选场景（60 个）：配方清单

> 「精选场景」不是上游素材，而是我们**在 594 条素材之上预先配好的 60 个成品配方**：每个都锁定「排版图型 + 画风 + 主题色 + 影调 + 比例 + 纯图/图文」，并给出一句适用说明与示例主题。
> 用户点「跟做」只需要填**自己的主题**，剩下 5 个参数已经配好（仍可逐个换）。
> 分 6 个域，每个域 10 个；编号 `CT-01 … CT-60`，与上游素材编号互不冲突（`CT-` 前缀）。
> 下表的「版式 / 画风 / 主题色 / 影调」都是**真实存在的上游编号**，实现时由 `scripts/build-catalog.mjs` 校验，任何一个 ID 不存在都会构建失败。

## 存储格式（`lib/data/curated.json`）

```json
{
  "version": 1,
  "items": [
    {
      "id": "CT-01",
      "domain": "knowledge",
      "title": "三分钟读懂一个概念",
      "titleEn": "Explain one concept in 3 minutes",
      "layout": "IG-032",
      "style": "FH-002",
      "color": "C-04",
      "tone": "T-01",
      "ratio": "4:5",
      "mode": "graphic-text",
      "themeHint": "为什么潮汐每天会晚 50 分钟",
      "cover": "layouts/infographics/IG-032.webp"
    }
  ]
}
```

- `cover` 直接复用该版式的官方示例图，**不新增素材**；60 张封面图进包内「封面集」（≈5.5 MB），保证首屏无需联网。
- 6 个域的值：`knowledge` 知识科普 / `work` 职场商业 / `life` 生活方式 / `commerce` 产品电商 / `ip` IP 品牌 / `story` 漫画叙事。
- 用户「跟做」后仍可在对话框里逐个换参数，换掉的参数会写进导出文件的 front matter，便于复现。
- 以后要加场景（比如扩到 100 个）只改这个 json，不动代码。
