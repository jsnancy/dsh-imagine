# 十六跟做图

用你已经付费的 **Codex（ChatGPT 订阅）**额度直接生图，并内置一套「照着做就行」的手绘模板库。它做四件事：

1. **读出账号额度** —— 套餐、本周已用百分比、重置时间、可用重置卡，全部来自本机 Codex CLI 的官方接口，不需要另外登录或填 API key。
2. **模板库一键跟做** —— 594 条上游素材 + 60 个成品场景配方；选定配方后，版式/画风/主题色/影调/比例都已锁定，你只写一句主题，拼装器按上游原文拼出提示词。
3. **一句话出图** —— 在侧栏写画面描述，选画布与背景，生成结果直接落成 PNG 存到本机并显示在面板里。
4. **留下历史** —— 每次生成的提示词、尺寸、耗时、token 用量都会记录，可复制描述、在访达中显示、下载或删除。

## 前置条件

- 本机装了 Codex CLI，并且已经用 ChatGPT 账号登录（`codex login status` 显示 `Logged in using ChatGPT`）。
- 能连通 `chatgpt.com`。如果你的网络需要代理，插件会自动探测常见的本地代理端口；也可以在面板「设置」里手动指定或关闭代理。

## 使用

侧栏点击「十六跟做图」图标进入面板。左侧栏四个入口：

- **模板库**：四个层级 —— 精选场景 60（成品配方，推荐从这里开始）、排版图型 170、画风 372、主题色·影调 52。可按分类筛选、按编号/名称/关键词搜索；每张卡片可「看大图」或「跟做」。看大图层可看官方示例图、参数与提示词全文，支持 ←/→ 翻页、复制、导出 `.md`。
- **一键跟做**：点卡片上的「跟做」弹出对话框，六个参数已按配方填好（可逐个换），写一句主题后自动拼装，预览区会显示字数与提示词全文；点「填充到创作页」把结果写进提示词框，画布比例同步，顶部出现「已套用模板」条（可清除或导出）。
- **自由组合**：创作页的「自由组合」按钮打开素材选择器 —— 排版图型 / 画风 / 主题色 / 影调各挑一个，还能开「角色画风」「场景画风」两个融合槽位；每挑一个，右侧预览就重拼一次。挑完点「填充到创作页」，顶部条会显示 `CUSTOM-…` 与所用编号。
- **筛选、收藏与最近使用**：模板库工具栏有「来源（全部 / 收藏 / 最近使用）」「模式」「比例」三个筛选，每张卡片右上角可点星标收藏；收藏与最近使用存在浏览器 localStorage，刷新后还在。
- **批量导出**：工具栏「导出当前筛选」「导出整个精选集」把对应条目全部拼好写进 `$DSH_HOME/image-studio/exports/<名称>-<日期时间>.md`，并自动在访达里定位；导出文件带 front matter、每条编号/配方/参数与末尾署名。
- **素材同步与缓存**：库头部「同步素材」在后台 3 并发把 594 张素材图下到本机（头部显示进度，完成后为「已全部缓存」）；「刷新缓存」重新计数。设置里可以设缓存上限（MB，0 = 不限）、清理缓存、全量重下。
- **本地仓库目录**：设置里填本地克隆的 handraw-style 根目录后，图片直接从本地读，不再联网 —— 完全离线可用。
- **参考图（垫图）**：创作页提示词框上方可「选择图片」（PNG / JPEG / WebP，≤12MB），生成时走 `images/edits` 让模型按当前画风重画它的构图与人物；如果账号后端不支持，面板会明确提示而不是静默失败。
- **AI 帮我配**：跟做对话框与素材选择器里的「AI 帮我配」让 DSH 默认模型只推荐六个编号（图型/画风/主题色/影调/比例/模式），提示词正文仍由拼装器按上游原文拼；模型没就绪时提示「AI 推荐失败」，不会阻塞手动选择。
- **生成图片 / 历史作品 / 账号与设置**：原有三块，创作页的「模板参考」横条可以随时把任意模板借用过来。

- **生成图片**：写提示词 → 选画布（自动 / 竖屏 / 横屏 / 方形）与背景（不透明 / 透明）→ 点「生成」或按 `⌘/Ctrl + Enter`。提示词下方提供三条示例，点一下就填入。
- **历史作品**：每次生成都是一张卡片，写着提示词、尺寸、体积与耗时。悬停图片会出现三个动作（在访达中显示、下载、删除），点图片进入全屏查看。
- **账号与设置**：套餐、每周额度、重置时间与可用重置卡；设置里可切换代理模式（自动 / 关闭 / 手动）、指定 Codex 可执行文件路径，或切换面板语言（中文 / English）。

首次使用如果账号没就绪，面板会给出登录引导。面板跟随 DSH 的浅色 / 深色主题，强调色会自动换档。

模型也可以直接调用这两个工具：

| 工具 | 作用 | 主要参数 |
| --- | --- | --- |
| `image_studio_generate` | 生成一张图片并保存 | `prompt`（必填）、`size`、`background` |
| `image_studio_quota` | 读取当前账号额度 | 无 |

`image_studio_generate` 返回图片在本机的绝对路径、尺寸、字节数与耗时，方便后续打开或引用。

## 模板库数据

- **索引内置**：594 条素材（372 画风 / 170 排版图型 / 36 主题色 / 16 影调）与 60 个场景配方的文本随插件发布，体积约 420 KB（gzip 后 38 KB）。
- **封面内置**：60 张场景封面随包发布（约 6.5 MB），首屏无需联网。
- **其余素材图按需拉取**：浏览或选用非内置素材时，Host 从 jsDelivr（失败回落 raw.githubusercontent）拉取并缓存在 `$DSH_HOME/image-studio/templates/assets`，同一张图只下载一次。也可以在库里点「同步素材」一次下完（594 张约 34 MB），或在设置里指向本地仓库目录彻底离线。
- **风格融合**：融合时主画风决定媒介、笔触与配色；「角色画风」「场景画风」只借用形体语言与氛围，提示词里会插入一段「融合原则」写明这个优先级。
- **拼装不改写**：提示词由上游原文按固定顺序拼接（画风 → 主题色 → 主题 → 比例 → 影调 → 留白 → 画面要求 → 排版图型），本插件只负责选料与排序，因此风格不会漂。
- **来源与署名**：数据来自 [yang0/handraw-style](https://github.com/yang0/handraw-style)（MIT + 署名要求）。面板底部、预览层与导出的 `.md` 都保留来源与作者信息。

## 界面风格（手绘皮肤）

面板是一张「手绘纸」，随 DSH 主题换物质：

- **浅色**：暖白纸底（`#fbf6ea`）+ 纸纹噪点 + 边缘暗角；炭笔色描边（`#2e2823`）、不规则圆角、硬阴影；朱砂（`#cf4a32`）做强调，马克笔黄做选中高亮；额度四格是四张不同颜色的便签，模板卡是轻微旋转的贴纸（带一条小胶带），提示词框是一页方格纸。
- **深色**：换成深咖啡纸（`#221c16`）+ 更粗的颗粒与粉笔白线（`#f3ebdc`），强调色提亮到 `#e8694f`，胶带变暗金、卡片变成深色纸片。

字体随功能分工：标题用翩翩体（HanziPen SC）、正文用手札体（Hannotate SC）、编号与计数用 Bradley Hand、长段提示词用娃娃体（Wawati SC），注释小字用系统无衬线体保证清晰。以上手写字体为 macOS 自带；其它系统会回落到系统无衬线体——版式与配色不变，手写感会减弱。

皮肤是一份独立样式表 `lib/skin-handdrawn.css`，由 Host 在 `/image-studio/skin.css` 提供，面板启动时注入 `<link>`。它只改观感，不改 DOM 结构与任何逻辑；想回到朴素界面，删掉 `lib/client.js` 中注入 `skin.css` 的那一段（搜索 `SKIN_ID`）即可。

## 额度是怎么读的

插件启动本机 Codex CLI 的 `app-server` 子进程，走官方 JSON-RPC 方法 `account/rateLimits/read` 取回套餐与额度窗口。这是一次只读查询：不会刷新 token，不会消耗额度，也不会改动你的 Codex 配置。账号身份、套餐、额度结果在面板里缓存 60 秒。

## 图片存在哪

```
$DSH_HOME/image-studio/images/<id>.png    # 生成的 PNG 原图
$DSH_HOME/image-studio/index.json         # 历史索引（提示词、尺寸、耗时、用量）
$DSH_HOME/image-studio/settings.json      # 面板设置
$DSH_HOME/image-studio/templates/assets/  # 同步/按需下载的模板素材图（594 张约 34 MB）
$DSH_HOME/image-studio/exports/           # 批量导出的 .md
```

`$DSH_HOME` 默认是 `~/.dsh`。文件只留在本机，插件不上传、不收集任何内容；只有发起生图时，提示词会随请求发送到 `chatgpt.com`。

## 已知限制

- **一次只出一张图**，并且尺寸是「建议值」：后端会按画面内容调整宽高比，实际尺寸以返回结果为准（面板会显示真实尺寸）。
- **透明背景**通常对应后端更高的一档生成质量，出图耗时与 token 用量会更高。
- 目前生图 provider 只有 Codex；Claude、WorkBuddy、Kimi 等订阅通道在面板里显示为「敬请期待」，接口层已经按 provider 预留。
- 生成是串行的，一次请求通常十几秒，面板里会显示实时耗时。
- 模板库的拼装结果固定为中文提示词；英文界面只翻译界面文案，不改提示词语言。
- 素材图默认依赖 GitHub CDN：完全断网时非内置素材的缩略图会缺失，内置封面与 60 个场景配方仍可用；点「同步素材」或配置本地仓库目录后即可离线。
- **垫图与出图受账号侧限制**：本机实测 `images/generations` 与 `images/edits` 都可能被后端返回 HTTP 403（连 Codex CLI 自带的 image_gen 工具同样 403）。此时面板「出图能力」显示「账号被后端拒绝出图」，垫图会报 `image-edit-forbidden`。这是账号/平台侧限制，插件不绕过。
- **AI 辅助需要 DSH 的 LLM 服务**：没有可用路由时返回 `llm-unavailable`，界面提示 AI 推荐失败。

## 清理

在插件详情页卸载即可移除插件本体。若要同时删掉图片与历史，删除 `$DSH_HOME/image-studio` 目录。
